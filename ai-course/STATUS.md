## How to build one lesson
Follow `course.md` § Build pipeline. Use 1.1 (`lessons/1.1-vectors/`) as the reference for structure and helpers, and 1.3 (`lessons/1.3-matrices/`) as the best example of a longer, carefully animated lesson. Run from `ai-course/`:
1. `narration.json` (scenes s1..sN) and `lesson.json`, then `python3 tools/check_lesson.py lessons/<id>` must print OK.
2. `python3 tools/tts.py lessons/<id>`. It reads `SARVAM_API_KEY` from the repo root `.env` (in Claude cloud sessions a proxy injected it instead). Then `python3 tools/voice.py lessons/<id>`.
3. `hf/index.html`: copy the scaffolding and helpers from an existing lesson, then anchor beats with `cue(sid,'word',n)`. Run `npx -y hyperframes@0.8.118 check` until it shows 0 errors, then `snapshot --at ...` and look at the contact sheets.
4. In `hf/`, run `npx -y hyperframes@0.8.118 render --quality delivery -o ../build/raw.mp4`, then master with the ffmpeg line in `course.md` into `build/<id>.mp4`. On macOS there is no `flock`; drop it if only one builder runs.
5. `python3 tools/otio_build.py lessons/<id>` (needs `opentimelineio`, which is in the repo's `.venv`), then `python3 tools/site_video.py lessons/<id>`, then `python3 tools/build_site.py`.
6. Commit the lesson folder, `site/videos/<id>.mp4`/`.jpg` and `site/data/`. Audio, `build/` and full-quality video are gitignored.

## Gotchas found while building
- The Hyperframes layout checker reports KaTeX's own stacked glyphs (hats, sub- and superscripts, `\neq`) as text overlaps. Put `data-layout-allow-overlap` on every `.katex` element (or its wrapper).
- Create and register the GSAP timeline in the same `<script>` block, or lint fails.
- Rotating a nested SVG group with `svgOrigin` inside a translated group lands in the wrong place; set the `transform` attribute directly instead.
- `voice.py` writes `timing.json` first and only then syncs `hf/index.html`. If the composition does not exist yet it skips the sync, so run it again once the composition is written.
- Background renders die if the session restarts; check that `build/<id>.mp4` exists before committing.
- Site copies of grid-heavy videos are large (1.3 and 1.4 are 11-12 MB). That is acceptable.
- Problems must be self-contained. Module 6 builds an autograd `Value` class and module 9 a NumPy GPT forward pass; each starter includes the previous lesson's working code.

## Claims stated from memory, not checked against a primary source
- **1.5, 1.7, 1.8:**
  - PageRank found its ranking as the leading eigenvector, computed by power iteration.
  - Vanishing or exploding stretch is "one reason" old RNNs forgot long sentences.
  - Eckart-Young.
  - LoRA's low-rank update ΔW = BA (Hu et al. 2021).
- **0.x, 1.2-1.4:**
  - "Billions of knobs" in large models.
  - Attention scores matches with dot products.
  - Transformer layers are mostly matrix products.
- **3.x, 4.x:**
  - Shannon 1948.
  - Adam (Kingma & Ba 2014); AdamW is usual for transformers.
  - Trillions of training tokens, vocabularies of tens of thousands of tokens.
  - A loss of about 11 at initialisation (ln 50,000).
  - Warm-up plus decay schedules.
  - Saddle points outnumber bad local minima in high dimensions (Dauphin et al.).
- **Not yet recorded:** the builders for 5.x, 6.x, 9.x and 10.x-12.x had not handed in reports when this was written. Check their narration, especially 10.1 (scaling laws), 10.3 (RLHF and DPO) and 11.x (diffusion), against the original papers.
- **5.6:**
  - k-nearest neighbours is described as learning no weights and storing every training example, with prediction-time comparison against stored points.
  - Distances between random points are described as becoming increasingly alike in high dimensions (the curse of dimensionality).
  - Retrieval-augmented generation is described as nearest-neighbour search over document embeddings, usually using cosine similarity and approximate search.
- **5.7:**
  - Random forests are described as using random resamples and feature subsets whose averaged votes reduce individual-tree instability.
  - Gradient boosting is described as adding trees sequentially to correct errors left by earlier trees.
  - Tree ensembles are described as among the strongest methods for tabular business data.
  - Mixture-of-experts language models are described as routing each token to a small subset of expert sub-networks.
- **5.8:**
  - K-means is described as alternating nearest-centroid assignment and centroid recomputation, monotonically reducing inertia until it reaches a local optimum; k-means++ is described as improving initialization.
  - The elbow method is described as a heuristic for choosing K, and k-means is described as working best for roughly round, similarly sized clusters.
  - Vector databases are described as using k-means in inverted-file indexing and product quantization to organize or compress embeddings.
- **5.9:**
  - PCA is described as finding covariance-matrix eigenvectors (or equivalently using SVD of centred data), with eigenvalues measuring variance along principal directions and SVD offering better numerical accuracy in practice.
  - Keeping enough components to reach 90-95% cumulative explained variance is described as a common rule of thumb.
  - Two-dimensional word-embedding illustrations are described as often using PCA and therefore showing only the directions of largest spread.
- **6.8:**
  - Batch normalisation is attributed to Ioffe and Szegedy (2015) and layer normalisation to Ba, Kiros and Hinton (2016).
  - The internal-covariate-shift explanation is described as debated, with later work pointing to a smoother loss landscape (Santurkar et al. 2018, not named in the narration).
  - GPT-2 is described as placing layer norm at the entrance of each sub-block (pre-norm), and LLaMA as using RMSNorm.
- **6.9:**
  - Dropout is attributed to Hinton's group around 2012 (Hinton et al. 2012; Srivastava et al. 2014).
  - The original transformer and the first GPT are described as using a dropout rate of 0.1.
  - Some of the largest language models are described as using little or no dropout in pre-training while it remains common in fine-tuning.
  - Weight scaling at test time is described as roughly averaging the predictions of all thinned networks.
- **7.1:**
  - Graphics cards are described as running one large matrix multiply much faster than many small ones.
- **7.2:**
  - Pretraining is described as running for tens or hundreds of thousands of steps across many machines.
  - The largest models are described as seeing most of their data only about once.
  - PyTorch is described as accumulating gradients by default, so they must be cleared before each backward pass.
- **7.3:**
  - Published large-model training reports are described as handling occasional loss spikes by restarting from an earlier checkpoint and skipping the batches that triggered them (PaLM, Chowdhery et al. 2022, is the source remembered; not checked).
  - A long plateau followed by a sudden drop is described as often meaning the model was stuck near a flat region.
- **7.4:**
  - PyTorch's cross-entropy loss is described as expecting raw logits, so applying softmax first squashes the signal and slows learning.
  - Teams training language models are described as running small versions first before spending real compute.
- **8.1:**
  - Deep learning libraries are described as computing cross-correlation (no kernel flip) while calling it convolution.
  - Vision transformers are described as beginning by cutting an image into patches with a strided convolution.
- **8.2:**
  - Visualisations of trained image networks are described as showing edges and colour blobs in early layers, textures and simple shapes in middle layers, and parts and whole objects deeper (Zeiler and Fergus 2014 is the work remembered; not checked).
  - Probing studies are described as suggesting that earlier language-model layers capture more about words and syntax and later ones more abstract meaning.
  - Many modern CNNs are described as replacing pooling with stride-2 convolutions and ending with global average pooling.
- **8.3:**
  - LeNet (Yann LeCun) is described as reading handwritten digits on bank cheques in the 1990s.
  - AlexNet (2012) is described as a much larger CNN trained on GPUs that won ImageNet by a wide margin and set off the deep learning boom.
  - The parameter counts (80, 1,168, 7,850) were checked by arithmetic.
- **8.4:**
  - He, Zhang, Ren and Sun (2015) are described as finding that 56-layer plain networks had higher training error than 20-layer ones.
  - Residual networks over a hundred layers deep are described as winning ImageNet in 2015, and the same paper as training a network of more than a thousand layers on a smaller dataset.
  - Shortcuts are described as using a 1×1 convolution projection when shapes change.
- **9.6:**
  - The formula softmax(QKᵀ/√d_k + M)V is attributed to Vaswani et al. 2017, "Attention Is All You Need".
  - A saturated softmax is described as passing back very little gradient, which motivates the √d_k scaling.
- **9.7:**
  - GPT-2 small is described as running twelve heads in each of its twelve layers.
  - Trained heads are described as specialising (previous token, grammatical dependencies), with some nearly redundant.
- **9.8:**
  - GPT-2 is described as learning its position vectors; the original transformer as using fixed sinusoids.
  - Rotary position embeddings (RoPE) are described as rotating q and k by a position-dependent angle.
- **9.9:**
  - GPT-2 small is described as stacking twelve blocks, with the MLP widening to four times the model width and using GELU.
  - Interpretability research is described as suggesting that much of what a model knows is stored in the MLP layers.
  - Pre-norm (GPT-2) is described as training more reliably in deep stacks than the original post-norm.
- **9.10:**
  - Greedy decoding is described as tending to repeat itself and drift into loops over longer passages.
  - A GPT-2-sized vocabulary is described as about fifty thousand tokens.
  - Nucleus (top-p) sampling is described as keeping the smallest set of tokens whose probabilities reach a chosen total.
- **12.1:**
  - RLHF is described as an MDP in which the state is the prompt plus text so far, an action is the next token, and the reward comes from the reward model at the end.
- **12.2:**
  - Q-learning is attributed to Watkins (1989), and its convergence proof to Watkins and Dayan (1992).
  - DQN (Mnih et al., 2015) is described as reaching about the level of a professional human tester on many of 49 Atari games, using a replay buffer and a target network.
- **12.3:**
  - REINFORCE is attributed to Ronald Williams (1992), and PPO to Schulman et al. at OpenAI (2017).
  - InstructGPT is described as using PPO with a learned value function as its baseline for its RL stage.
- **C1:**
  - MNIST is described as 70,000 28×28 greyscale digit images (60,000 train, 10,000 test).
  - A 784-128-10 MLP is described as typically reaching about 97-98% on MNIST within a few epochs.
  - Common confusions (4↔9, 3↔5, unusual 7s) are illustrative, not measured.
- **C2:**
  - The Shakespeare character corpus (about a million characters) is described as popularised by Andrej Karpathy.
  - A model of a few million parameters is described as learning a great deal on a single GPU in a few thousand steps.
  - The sample texts and loss curves in the video are illustrative, not measured.
